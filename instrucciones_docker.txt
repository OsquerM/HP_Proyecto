PASOS COMPLETOS PARA PC NUEVO
1. Preparación inicial

Copia o clona el proyecto completo en el nuevo PC.
Abre Git Bash y navega a la carpeta del proyecto:Bashcd C:/ruta/a/HP_Proyecto_Docker

2. Levantar Docker (primera vez)
Bashd ocker compose up --build -d
Espera hasta que termine.
3. Verificar que todo esté funcionando
Bashdocker compose ps
Deberías ver hp_mariadb y hp_quiz_app en estado Up.
4. Crear el usuario Admin
Bashdocker compose exec hp_quiz_app python crear_admin.py
5. Acceder al proyecto
Abre el navegador y entra en:

Página principal: http://localhost:8000
Panel de Admin: http://localhost:8000/admin/login

Usuario: admin
Contraseña: 1234
6. Crear las preguntas manualmente

Entra al panel de admin.
Crea tus 8 preguntas con sus respectivas respuestas e imágenes.


Comandos útiles (para tener a mano)
Bash# Reiniciar todo
docker compose restart

# Ver logs
docker compose logs hp_quiz_app -f

# Parar todo
docker compose down
